# Logic Gates Using Verilog HDL

## Project Overview
This beginner VLSI project implements six basic digital logic gates using Verilog Hardware Description Language (HDL).

## Logic Gates Implemented
- AND
- OR
- NOT
- NAND
- NOR
- XOR

## Tools Used
- Verilog HDL
- EDA Playground
- Icarus Verilog simulator

## Project Files
- `logic_gates.v` — Verilog design for the six logic gates.
- `tb_logic_gates.v` — Testbench used to verify the design.

## Verification
The testbench applies all four possible input combinations for the two binary inputs. The simulation output was checked against the expected truth table.

**Result:** All six logic-gate outputs matched the expected truth table for all tested input combinations.
